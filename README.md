# 情绪键帽 · 桌宠小屋

[在线试玩](https://yuliye0409-hue.github.io/emotion-keycaps/)

在线版可给咔粒换装、体验各房间的互动。要把键帽放到 Windows 桌面，请下载仓库并按下面的本机预览说明启动。

在本目录运行 `node preview.mjs`，访问 `http://127.0.0.1:4178/`。可用 `node preview.mjs 4180` 指定端口。网页版也能直接打开 `index.html`，置顶桌宠建议通过本机预览地址启动。

在换装工作台可给 ESC 键帽「咔粒」换颜色、表情、配件和昵称，换房间时也会穿着这套搭配。点键帽或下方按键互动；每个房间的紫色按钮和场景内道具会触发专属动作，并留下一件纪念物。角色设置与每个房间最近四条日记保存在当前浏览器，不用登录。

在网页上，空格运动、W 喝水、S 睡觉／叫醒、B 敲键帽、H 打招呼、E 触发房间动作。

咔粒会在互动的不同阶段切换表情和姿势，动作结束后回到换装时选好的表情。网页有焦点时，帽顶会显示当前按下的键，约 1.8 秒后回到 ESC。

Windows 上用本机预览打开网页后，点「放到桌面」，桌面会出现当前键帽，关闭网页后仍可互动。左键轻戳，双击轻敲，按住拖动，鼠标在角色身上停留 1 秒会在周围弹出独立的互动气泡。移到任意气泡上，桌宠会看向它，点击即可互动。换装后可以再点一次「放到桌面」更新同一只桌宠。桌宠获得焦点时支持 W、S、空格、B、H 和 Esc。首次启动使用 Windows 自带的 .NET Framework 编译宿主。

本机预览仅监听回环地址。网页版使用静态文件，无第三方运行依赖。

勾选网页的「启用桌宠的办公陪伴提醒」后点「放到桌面」，也可用互动气泡里的「陪伴」开关。使用电脑期间，约 3 分钟没互动时桌宠会露出委屈脸，约 6 分钟时掉眼泪，点它或抱一下就会恢复。连续快速按键会触发询问和暂停牌，两次提醒至少相隔 4 分钟。离开电脑后回来会收到招呼，持续使用约 25 分钟后会收到伸展提醒。打字速度由本机短时间内的松键次数计算。

Windows 桌宠可以在其他窗口获得焦点时同步显示最后一个按键的键名。键名仅用于本机即时绘制，约 1.8 秒后清除。分享屏幕或输入密码前，可以取消勾选网页上的「在 Windows 桌宠上显示当前按键」，再点一次「放到桌面」应用设置。
