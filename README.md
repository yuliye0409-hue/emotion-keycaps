# 情绪键帽 · 桌宠小屋

[在线试玩](https://yuliye0409-hue.github.io/emotion-keycaps/)

在线版可给咔粒换装、体验各房间的互动。要把键帽放到 Windows 桌面，请下载仓库并按下面的本机预览说明启动。

## 本机预览

在本目录运行 `node preview.mjs`，访问 `http://127.0.0.1:4178/`。可用 `node preview.mjs 4180` 指定端口。直接打开 `index.html` 或设备不支持 WebGL 时，网页会保留插画版。

「咔粒的家」把客厅、厨房、卧室和复习桌连在同一个三维空间里。点击或触摸地面、门槛或门牌，让咔粒走过去；也可用方向键或 WASD 移动。咔粒穿过实际门洞时，房间名和互动随位置更新。拖动画面可绕视，右上角可看整屋或近看角色。点厨房的锅、客厅的唱片机、卧室的床或复习桌的书签，咔粒会走到附近再互动。厨房可以做南瓜浓汤或果酱吐司，端上桌后可以一起尝。空闲时咔粒会偶尔自己听唱片或翻书。

在换装工作台可给 ESC 键帽「咔粒」更换表情、配饰和昵称。先选部位，再通过 HSV 调色盘、滑块或 HEX 色号调色，搭配会随咔粒一起换房间。角色设置与每个房间最近四条日记保存在当前浏览器，不用登录。

在网页上，空格运动、B 敲键帽、H 打招呼、E 触发房间动作。插画版另外支持 W 喝水、S 睡觉／叫醒；三维版可以通过场景下方的对应按钮操作。

咔粒会在互动的不同阶段切换表情和姿势，动作结束后回到换装时选好的表情。网页有焦点时，帽顶会显示当前按下的键，约 1.8 秒后回到 ESC。

换装工作台有 55 个预设表情。咔粒会仰躺在床垫上盖好被子，喝水时会用短手抱住杯子，把吸管送到嘴边。点「躲猫猫」后，它会跳进纸箱等你来找。藏好后点纸箱，就能看到它探头、再跳出来。网页版也可以用键盘聚焦「找咔粒」或纸箱后按回车。

Windows 上用本机预览打开网页后，点「放到桌面」，桌宠会在当前屏幕右下角挥手，关闭网页后仍可互动。左键轻戳，双击轻敲，按住拖动，鼠标在角色身上停留 1 秒会在周围弹出独立的互动气泡。移到任意气泡上，桌宠会看向它，点击即可互动。换装后点击工作台的「更新桌宠装扮」，桌宠会在原处换上新搭配。桌宠获得焦点时支持 W、S、空格、B、H 和 Esc。首次启动使用 Windows 自带的 .NET Framework 编译宿主。

本机预览仅监听回环地址。网页版使用静态文件，三维渲染使用仓库内的 Three.js，不依赖 CDN。

勾选网页的「启用桌宠的办公陪伴提醒」后点「放到桌面」，也可用互动气泡里的「陪伴」开关。使用电脑期间，约 3 分钟没互动时桌宠会露出委屈脸，约 6 分钟时掉眼泪，点它或抱一下就会恢复。连续快速按键会触发询问和暂停牌，两次提醒至少相隔 4 分钟。离开电脑后回来会收到招呼，持续使用约 25 分钟后会收到伸展提醒。打字速度由本机短时间内的松键次数计算。

Windows 桌宠可以在其他窗口获得焦点时同步显示最后一个按键的键名。键名仅用于本机即时绘制，约 1.8 秒后清除。分享屏幕或输入密码前，可以取消勾选网页上的「在 Windows 桌宠上显示当前按键」，再点一次「放到桌面」应用设置。
